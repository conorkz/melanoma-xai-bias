# Paper

LaTeX manuscript for the architecture, fairness, calibration, and XAI study.

## Files

- `main.tex`: document setup, abstract, and section inputs.
- `sections/`: introduction, related work, methods, results, discussion, limitations, ethics, and conclusion.
- `tables/`: generated by `scripts/build_paper_tables.py`.
- `figures/`: Stage 2 ROC and training curves, fairness, dark-skin robustness, XAI, and calibration figures.
- `references.bib`: 38 verified entries.
- `cover_letter.md`: draft cover letter with journal and affiliation placeholders.
- `submission_checklist.md`: journal, metadata, scientific, and file checks.

## Compile

On Overleaf, upload the `paper/` folder, set `main.tex` as the main file, choose pdfLaTeX, and use BibTeX. The `tables/` and `figures/` paths are relative to `main.tex`.

Locally, with tectonic:

```bash
tectonic paper/main.tex
```

Or with a standard TeX installation:

```bash
cd paper
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

## Regenerate the tables

```bash
.venv/bin/python scripts/build_paper_tables.py
```

The script reads the Stage 1 and Stage 2 CSVs, the fairness summary, the dark-skin cutoff and adjusted-model results, the calibration summary, the ranking summary, the XAI summaries, and the external validation summary. Do not edit the table files by hand.

## Reproduce the analyses

```bash
# Dark-skin contrast features and robustness
.venv/bin/python scripts/build_contrast_table.py
.venv/bin/python scripts/analyze_dark_skin.py --n-boot 300
.venv/bin/python scripts/plot_fairness.py

# Calibration and paired ranking tests
.venv/bin/python scripts/analyze_calibration.py
.venv/bin/python scripts/analyze_ranking.py

# XAI
.venv/bin/python scripts/analyze_xai.py --backbones efficientnet_b0 --seeds 1,2,3 --max-images 150 --out-dir results/xai/efficientnet_b0
.venv/bin/python scripts/analyze_xai.py --backbones resnet50 --seeds 1,2,3 --max-images 150 --out-dir results/xai/resnet50
.venv/bin/python scripts/analyze_xai.py --backbones vit_s --seeds 1,2,3 --max-images 150 --out-dir results/xai/vit_s
.venv/bin/python scripts/combine_xai_results.py
.venv/bin/python scripts/plot_xai.py

# External validation
.venv/bin/python scripts/evaluate_external.py --device mps --merge --out-dir results/external/hiba
```

## Writing rules

- No em dashes or en dashes.
- Every number comes from a result CSV.
- Every table is generated by a script.
- Call the L* groups image-based lightness strata, not Fitzpatrick labels.
- Keep the test set out of model selection.
