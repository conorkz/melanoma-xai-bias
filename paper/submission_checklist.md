## Scientific checks

- [ ] Every number in the paper traces to a CSV under `results/`.
- [ ] The test split was not used for model selection.
- [ ] The three seeds and the lesion-aware split are stated.
- [ ] The paired tests and calibration analysis are reported.
- [ ] The cutoff sensitivity analysis is reported.
- [ ] The false-positive and false-negative models are reported.
- [ ] The external validation is reported with the frozen threshold.
- [ ] The oracle 95% specificity result is labeled as an upper bound.
- [ ] The Fitzpatrick IV and V-VI limitations are stated.

## References

- [ ] Every reference resolves with a DOI or arXiv identifier.
- [ ] The reference style matches the journal.
- [ ] The HIBA, PROVe-AI, SCIN, and PASSION entries have complete author lists.
- [ ] No preprint is cited where a peer-reviewed version exists.

## Figures and tables

- [ ] Figures are 300 dpi or vector.
- [ ] Color palettes are colorblind-safe.
- [ ] Tables are generated by `scripts/build_paper_tables.py`.
- [ ] Table captions define every abbreviation.
- [ ] Figure captions state the sample size and the error bars.
